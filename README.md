# Easy Card Game

一款使用 Godot 4.6 开发的类杀戮尖塔卡牌游戏。

## 功能特性

### 战斗系统
- 状态机驱动的战斗流程
- 回合管理系统
- 无能量限制，注重卡组运转
- 游戏王模式：弃牌堆不自动洗回，需要卡牌效果触发循环

### 角色系统
- 角色创建：属性点分配、卡组构筑
- 角色数值：力量、敏捷等属性影响卡牌效果
- 永久成长：战斗后可强化卡牌、获得新卡

### 卡牌系统
- 标签系统：支持卡牌分类、字段伪装
- 多种效果：伤害、护甲、检索、消耗等
- 卡牌强化：提升卡牌倍率或数值

### 存档系统
- 自动保存游戏进度
- 支持继续游戏功能

## 技术栈

- **引擎**: Godot 4.6
- **语言**: GDScript
- **架构**: MVC 模式、状态机模式

## 项目结构

```
card/
├── data/              # 数据文件
│   ├── cards/         # 卡牌定义
│   ├── enemies/       # 敌人定义
│   └── tags.json      # 标签配置
├── scenes/            # 场景文件
├── scripts/           # 脚本文件
│   ├── battle/        # 战斗系统
│   ├── effects/       # 效果系统
│   ├── systems/       # 核心系统
│   └── ui/            # UI脚本
└── project.godot      # 项目配置
```

## 运行方式

1. 安装 Godot 4.6
2. 打开项目：导入 `project.godot`
3. 运行：按 F5 或点击运行按钮
