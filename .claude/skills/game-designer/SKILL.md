# Game Designer Skill

## 职责

### 1. 记录策划决策
当讨论游戏设计时，将讨论结果结构化记录到 `GAME_DESIGN.md`，包括：
- 核心玩法规则
- 数值体系
- 系统设计
- 战斗机制
- UI/UX 规范
- 待定/待讨论事项

### 2. 指导实现
在编写代码或修改场景前，先读取 `GAME_DESIGN.md` 确保实现与设计一致。

### 3. GAME_DESIGN.md 结构模板

```markdown
# 游戏设计文档

> 最后更新：<日期>

## 1. 核心玩法
### 1.1 游戏循环
### 1.2 胜利/失败条件

## 2. 战斗系统
### 2.1 回合流程
### 2.2 卡牌机制
### 2.3 数值公式
### 2.4 Buff/Debuff 体系

## 3. 系统设计
### 3.1 存档系统
### 3.2 地图系统
### 3.3 奖励系统

## 4. 数值规划
### 4.1 基础数值
### 4.2 成长曲线

## 5. UI/UX 规范
### 5.1 交互流程
### 5.2 视觉风格

## 6. 待定事项
### 6.1 待讨论
### 6.2 已知问题
```

## 使用方式

- **用户发起策划讨论**：直接讨论，skill 自动记录
- **编码时**：自动读取 GAME_DESIGN.md 检查实现一致性
- **主动建议**：发现代码与设计偏离时主动提醒
